# Probashi Footballers - Project Context

## Project Overview

Probashi Footballers is a community-driven project that tracks football players of Bangladeshi heritage living and playing outside Bangladesh.

The project's primary goals are:

- Identify new diaspora players
- Track player development
- Track club and national team changes
- Support Bangladesh football talent identification
- Maintain a historical record of player information

Website repository:

https://github.com/dr-shiffles/probashi-footballers

# Design Philosophy

Prioritize simplicity.

Preferred:

- CSV
- JSON
- Static HTML
- JavaScript
- GitHub
- Cloudflare Pages

Avoid:

- Backend servers
- Microservices
- Database servers
- Complex frameworks

The project should remain maintainable by a single volunteer.

---

# AI Objectives

The AI should help:

- Extract player information
- Generate structured records
- Detect duplicate players
- Compare records
- Generate CSV updates
- Generate changelog entries
- Generate social media update reports
- Assist with validation

The AI should not:

- Modify deployment workflows
- Edit lastUpdate.json
- Introduce unnecessary infrastructure
- Delete historical records without approval
